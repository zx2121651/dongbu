# YOLOv8 动画桌面捕捉软件 v2.0 (GUI版)

本项目是一个使用 `YOLOv8` 和 `Tkinter` 实现的单人和多人动画桌面捕捉软件。它能实时捕捉您的屏幕（全屏或指定区域），检测画面中的人物，并根据检测到的身体关键点（姿态）生成一个可定制、可平滑过渡的动画角色，最后将动画实时显示在一个带图形用户界面（GUI）的独立窗口中。

## ✨ 主要功能

- **图形用户界面 (GUI)**:
    - 使用 `Tkinter` 构建，提供一个独立的设置面板来控制所有主要功能。
    - 实时视频/动画预览窗口。
- **高性能捕捉模式**:
    - **指定区域捕捉 (ROI)**: 允许用户通过鼠标拖拽选择屏幕上的任意区域进行捕捉，极大地提升了性能和帧率。
    - **全屏捕捉**: 同时保留了捕捉整个主显示器的模式。
- **高级动画效果**:
    - **姿态平滑**: 采用基于跟踪ID的线性插值算法，有效减少动画抖动，使角色动作更流畅。
    - **可定制角色**: 通过GUI下拉菜单选择不同的角色外观（颜色、粗细）。
    - **动画预览**: 在设置面板中实时预览所选角色的外观。
- **灵活的视图模式**:
    - **动画视图**: 在纯色或自定义图片背景上显示动画角色。
    - **视频骨骼预览**: 直接在原始捕捉画面上叠加显示检测到的骨骼线条，方便调试和观察。
- **丰富的控制选项**:
    - **背景切换**: 通过GUI下拉菜单选择纯色或自定义图片背景。
    - **阈值调整**: 通过GUI滑块动态调整姿态检测的置信度阈值。
    - **平滑度调整**: 通过GUI滑块实时控制动画的平滑程度。
    - **视频录制**: 通过GUI按钮方便地开始和停止录制，将动画保存为 `output.mp4`。

## 📦 安装指南

1.  **克隆或下载项目**:
    将本项目所有文件下载到您的本地文件夹。

2.  **创建Python虚拟环境 (推荐)**:
    ```bash
    python -m venv venv
    source venv/bin/activate  # 在 Windows 上使用 `venv\Scripts\activate`
    ```

3.  **安装依赖**:
    ```bash
    pip install -r requirements.txt
    ```

## 🚀 使用方法

1.  **运行程序**:
    在您的终端或命令行中，进入项目文件夹，然后运行主程序：
    ```bash
    python main_gui.py
    ```
    程序启动后，会弹出一个带设置面板的窗口。后台线程会开始捕捉全屏画面并显示动画。

2.  **使用GUI设置面板**:
    窗口右侧的面板提供了对所有功能的控制：
    - **选择捕捉区域**: 点击后主窗口会隐藏，屏幕变暗，此时您可以按住鼠标左键拖拽出一个矩形区域。松开鼠标后，程序将只捕捉该区域。
    - **重置为全屏**: 点击后恢复对整个主显示器的捕捉。
    - **视图模式**: 选择“动画视图”或“视频骨骼预览”。
    - **角色外观**: 从下拉菜单选择不同的角色风格。
    - **背景**: 从下拉菜单选择不同的背景（仅在动画视图下有效）。
    - **置信度阈值**: 拖动滑块以过滤掉低置信度的检测结果。
    - **动画平滑度**: 拖动滑块调整动画的流畅度。值越高越平滑，但延迟感也可能略高。
    - **外观预览**: 实时显示当前选择的角色外观。
    - **开始/停止录制**: 点击按钮来开始或停止录制视频。

3.  **自定义背景 (可选)**:
    如果您想使用自己的图片作为背景，请将一张图片命名为 `background.jpg` 并放置在与 `main_gui.py` 相同的目录下。程序启动时会自动检测并将其加入到背景下拉菜单中。

## 📝 注意事项

- **性能**: 如果感觉卡顿，强烈建议使用“选择捕捉区域”功能并选择一个较小的区域，这会显著提升帧率。
- **首次运行**: 首次运行 `main_gui.py` 时，`ultralytics` 库会自动下载所需的 `yolo11n-pose.pt` 模型文件。请确保您的网络连接正常。
