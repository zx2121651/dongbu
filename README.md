# YOLOv8 动画桌面捕捉软件

本项目是一个使用 `YOLOv8` 实现的单人和多人动画桌面捕捉软件。它能实时捕捉您的主显示器屏幕，检测画面中的人物，并根据检测到的身体关键点（姿态）生成一个可定制的动画角色，最后将动画实时显示在一个独立的窗口中。

## ✨ 主要功能

- **实时屏幕捕捉**: 高效捕捉主显示器的画面作为输入。
- **多人姿态估计**: 基于强大的 `YOLOv8-Pose` 模型，能够同时检测和跟踪屏幕上多个人的身体姿态。
- **可定制动画角色**:
    - **几何体风格**: 使用彩色的几何图形（矩形和圆形）来构成角色身体，而非简单的火柴棍。
    - **外观切换**: 内置多种角色外观配置文件（例如“默认”和“单色”），用户可以一键切换角色的颜色和粗细。
- **可更换背景**:
    - 支持纯色背景（黑色、蓝色）。
    - 支持用户自定义图片背景 (需提供 `background.jpg` 文件)。
    - 可在不同背景之间一键切换。
- **视频录制**: 可以将生成的动画画面实时录制成视频文件 (`output.mp4`)。
- **状态显示 (HUD)**: 在输出窗口的左上角清晰地显示当前状态（如录制状态、角色外观、背景模式）和热键提示。

## 📦 安装指南

1.  **克隆或下载项目**:
    将本项目文件（`main.py`, `requirements.txt`, `README.md`）下载到您的本地文件夹。

2.  **创建Python虚拟环境 (推荐)**:
    ```bash
    python -m venv venv
    source venv/bin/activate  # 在 Windows 上使用 `venv\Scripts\activate`
    ```

3.  **安装依赖**:
    项目所需的依赖库已在 `requirements.txt` 文件中列出。通过以下命令进行安装：
    ```bash
    pip install -r requirements.txt
    ```

## 🚀 使用方法

1.  **运行程序**:
    在您的终端或命令行中，进入项目文件夹，然后运行主程序：
    ```bash
    python main.py
    ```
    程序启动后，会首先加载YOLOv8模型（可能需要几秒钟），然后会弹出一个名为 "Animation Desktop Capture" 的窗口，实时显示生成的动画。

2.  **自定义背景 (可选)**:
    如果您想使用自己的图片作为背景，请将一张图片命名为 `background.jpg` 并放置在与 `main.py` 相同的目录下。程序启动时会自动检测并加载它。

3.  **交互热键**:
    请确保 "Animation Desktop Capture" 窗口处于**激活状态**（鼠标点击一下窗口），然后使用以下热键进行交互：

    - `q`: **退出**程序。
    - `c`: **切换角色外观** (Character)。在不同的预设颜色和风格之间循环切换。
    - `b`: **切换背景** (Background)。在纯黑、纯蓝和自定义图片背景之间循环切换。
    - `r`: **开始/停止录制** (Record)。按下后开始录制，再按一下停止。录制状态会显示在左上角的HUD中。视频文件将保存为 `output.mp4`。

## 📝 注意事项

- **性能**: 程序的运行速度（帧率）主要取决于您计算机的CPU/GPU性能。`yolo11n-pose.pt` 是一个轻量级模型，但实时处理高分辨率屏幕仍然需要一定的计算资源。
- **主显示器**: 程序默认捕捉您的主显示器 (`sct.monitors[1]`)。
- **首次运行**: 首次运行 `main.py` 时，`ultralytics` 库会自动下载所需的 `yolo11n-pose.pt` 模型文件。请确保您的网络连接正常。
