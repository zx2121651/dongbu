# YOLOv8 动画桌面捕捉软件 v3.0 (CustomTkinter GUI)

本项目是一个使用 `YOLOv8` 和 `CustomTkinter` 实现的单人和多人动画桌面捕捉软件。它能实时捕捉您的屏幕（全屏或指定区域），检测画面中的人物，并根据检测到的身体关键点（姿态）生成一个可定制、可平滑过渡的动画角色，最后将动画实时显示在一个带现代化图形用户界面（GUI）的独立窗口中。

## ✨ 主要功能

- **现代化图形用户界面 (GUI)**:
    - 使用 `CustomTkinter` 构建，提供一个带**深色主题**的、布局清晰的设置面板。
    - 所有控件（按钮、滑块、下拉菜单等）都具有现代化的外观和感觉。
    - 设置面板**可滚动**，以容纳所有功能选项。
- **高性能捕捉与检测**:
    - **模型选择**: 允许用户在不同的YOLOv8姿态模型（n, s, m）之间切换，以在**速度和精度**之间取得平衡。
    - **指定区域捕捉 (ROI)**: 允许用户通过鼠标拖拽选择屏幕上的任意区域进行捕捉，极大地提升了性能和帧率。
- **高级动画效果**:
    - **高级平滑 (1-Euro Filter)**: 采用先进的一欧元滤波器，有效抑制噪声和抖动，同时在快速移动时保持低延迟。
    - **可定制角色**: 通过GUI下拉菜单选择不同的角色外观（颜色、粗细）。
    - **动画预览**: 在设置面板中实时预览所选角色的外观。
- **灵活的视图模式**:
    - **动画视图**: 在纯色或自定义图片背景上显示动画角色。
    - **视频骨骼预览**: 直接在原始捕捉画面上叠加显示检测到的骨骼线条，方便调试和观察。
- **丰富的控制选项**:
    - **滤波器参数调整**: 通过GUI滑块微调一欧元滤波器的 `min_cutoff` 和 `beta` 参数。
    - **背景切换**: 通过GUI下拉菜单选择纯色或自定义图片背景。
    - **阈值调整**: 通过GUI滑块动态调整姿态检测的置信度阈值。
    - **视频录制**: 通过GUI按钮方便地开始和停止录制，将动画保存为 `output.mp4`。

## 📦 安装指南

1.  **克隆或下载项目**:
    将本项目所有文件下载到您的本地文件夹。

2.  **创建Python虚拟环境 (推荐)**:
    ```bash
    python -m venv venv
    source venv/bin/activate  # 在 Windows 上使用 `venv\Scripts\activate`
    ```

3.  **安装依赖**:
    ```bash
    pip install -r requirements.txt
    ```

## 🚀 使用方法

1.  **运行程序**:
    在您的终端或命令行中，进入项目文件夹，然后运行主程序：
    ```bash
    python main_gui.py
    ```
    程序启动后，会弹出一个带设置面板的深色主题窗口。

2.  **使用GUI设置面板**:
    窗口右侧的面板提供了对所有功能的控制，这些功能被清晰地分组在不同的区域中：
    - **捕捉与模型**:
        - `选择捕捉区域`: 点击后可用鼠标选择屏幕上的特定区域。
        - `重置为全屏`: 恢复全屏捕捉。
        - `检测模型`: 选择YOLOv8模型 (`n`最快, `m`最准)。
    - **外观与视图**:
        - `视图模式`: 在“动画视图”和“视频骨骼预览”之间切换。
        - `角色外观`: 选择不同的角色颜色和风格。
    - **效果与参数**:
        - `置信度`: 调整模型检测的灵敏度。
        - `Min Cutoff` / `Beta`: 微调平滑滤波器的参数以获得最佳效果。
    - **外观预览**: 实时显示当前选择的角色外观。
    - **开始/停止录制**: 点击按钮来开始或停止录制视频。

3.  **自定义背景 (可选)**:
    如果您想使用自己的图片作为背景，请将一张图片命名为 `background.jpg` 并放置在与 `main_gui.py` 相同的目录下。程序启动时会自动检测并将其加入到背景下拉菜单中。

## 📝 注意事项

- **性能**: 如果感觉卡顿，强烈建议使用“选择捕捉区域”功能并选择一个较小的区域，或者切换到更小的检测模型（如`yolo11n-pose.pt`）。
- **首次运行**: 首次运行或切换到一个新模型时，`ultralytics` 库会自动下载所需的模型文件。请确保您的网络连接正常。
