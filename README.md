# YOLOv8 动画桌面捕捉软件 v4.0 (PyQt6 Refactor)

本项目是一个使用 `YOLOv8` 实现的单人和多人动画桌面捕捉软件。**此版本已将UI框架从Tkinter/CustomTkinter重构为更强大、更专业的PyQt6。**

这个重构的第一阶段已经完成，目前实现了基于PyQt6的应用核心架构。

## ✨ 当前阶段功能

- **PyQt6 应用程序框架**:
    - 使用 `PyQt6` 构建了主应用程序窗口 (`QMainWindow`)。
    - 实现了专业的、线程安全的后台处理架构。
- **后台线程与信号/槽通信**:
    - 核心的屏幕捕捉和姿态估计逻辑运行在一个独立的 `QThread` 中，以确保UI界面的流畅。
    - 使用 `PyQt6` 的**信号与槽机制**在后台线程和主UI线程之间进行通信，这是比之前更稳定和高效的方式。
- **实时视频显示**:
    - 后台线程处理完成的每一帧图像都会通过信号发送到主窗口。
    - 主窗口的槽函数接收到图像后，会将其转换为`QPixmap`并实时显示在界面上。
- **保留的核心逻辑**:
    - 后台线程依然保留了之前版本的所有核心功能，包括：模型加载、屏幕捕捉、姿态跟踪、一欧元滤波器平滑、以及根据不同视图模式生成图像的逻辑。**（注意：控制这些功能的UI控件将在下一阶段添加）**

## 📂 项目结构

```
.
├── main_pyqt.py        # PyQt6 GUI应用程序主入口
├── capture_thread.py   # 后台捕捉与处理线程 (已适配PyQt6)
├── drawing.py          # 绘图相关函数
├── config.py           # 静态配置文件
├── roi_selector.py     # 屏幕区域选择器UI (暂未集成到PyQt版)
├── one_euro_filter.py  # 一欧元滤波器实现
├── requirements.txt    # 依赖库 (已更新为PyQt6)
└── README.md           # 本文档
```

## 📦 安装指南

1.  **克隆或下载项目**
2.  **创建Python虚拟环境 (推荐)**
3.  **安装依赖**:
    ```bash
    pip install -r requirements.txt
    ```

## 🚀 使用方法

在您的终端或命令行中，进入项目文件夹，然后运行主程序：
```bash
python main_pyqt.py
```
程序启动后，会弹出一个PyQt6窗口，并开始显示后台线程处理后的实时画面（默认为动画视图）。**当前版本暂无UI交互控件。**
